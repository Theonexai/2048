# Contributing

Changes and fixes are welcome. Please keep the game lightweight, preserve standard 2048 rules, and retain the upstream attribution and license notice in [LICENSE.txt](LICENSE.txt).

The active page stylesheet is `style/hopmint.css`. The older `style/main.scss` and `style/main.css` files are retained as upstream source material and are no longer loaded by the page.

There is no build step. To preview locally, run `python -m http.server 8000` from the project directory and open `http://localhost:8000`.
